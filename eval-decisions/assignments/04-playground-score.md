# Assignment 04: Playground: score rubric

| | |
|---|---|
| **Duration** | 30 minutes |
| **Level** | Basic |
| **Module** | Foundations |
| **Domain** | Customer support — route, escalate, gate refund tool |

## Objective

Use ordered levels for severity or urgency.

## Steps

1. Define 3 levels: low / medium / high with distinct criteria.
2. Score 4 tickets from cosmetic issue → blocked workflow.
3. Record numeric `score` and `confidence` each time.
4. Write one sentence: when `score` falls between levels, what happens next?

## Deliverable

Rubric text + 4 scored examples in `eval-decisions/spec/playground_score.md`.

## Done when

Adjacent levels are clearly distinguishable in wording.
